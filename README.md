# Hotel Management App

A comprehensive mobile application for small hotel management built with native Android (Kotlin) and Python backend.

## Features
- User authentication with OTP verification
- Hotel profile customization
- Billing & Invoice management
- Menu handling
- Reports & Analytics
- Dashboard

## Tech Stack
- **Frontend:** Native Android (Kotlin)
- **Backend:** Python (Flask/FastAPI)
- **Database:** PostgreSQL
- **Authentication:** OTP via SMS

## Project Structure
```
hotel-management-app/
├── backend/           # Python backend
├── android/           # Android app (Kotlin)
├── docs/              # Documentation
└── README.md
```

## Getting Started

### Backend Setup
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Android Setup
```bash
cd android
./gradlew build
```
